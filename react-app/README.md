# Patient Studio (React)

The faculty-facing authoring tool for building simulated patients, ported from the
single-file HTML prototype to a Vite + React app.

## Run it

You need [Node.js](https://nodejs.org) 18+ installed first.

```bash
cd react-app
npm install
npm run dev
```

Vite prints a local URL (usually http://localhost:5173). Open it in a browser.

To make a production build:

```bash
npm run build     # outputs to dist/
npm run preview   # serve the built app locally
```

## Structure

```
react-app/
  index.html              Vite entry HTML
  vite.config.js          Vite + React plugin config
  src/
    main.jsx              Mounts <App/>
    App.jsx               Top-level state: patient library, persistence, actions
    styles.css            Design tokens and layout (unchanged from the prototype)
    studio.js             Pure logic: data model, consistency checks, encounter export
    components/
      Sidebar.jsx         Patient library list + "New patient"
      Editor.jsx          The five editing cards for the selected patient
      Results.jsx         Consistency / publish result panel
      Fields.jsx          Small reusable form controls
```

## Notes

- Patients persist in the browser via `localStorage` under the key `twinverse.studio`,
  matching the original prototype, so existing saved data carries over.
- Clinical facts no longer include a "what the patient says" field. The patient's
  spoken reply is generated by the AI at encounter time from what the chart shows,
  so faculty only enter the chart fact and its release words.
